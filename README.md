🌦️ Weather App
A responsive weather application that provides real-time weather information for any city around the world. 
The application fetches live weather data using a weather API 
and displays details such as temperature, humidity, wind speed, 
and weather conditions in a clean and user-friendly interface.
🚀 Features
🔍 Search weather by city name
🌡️ Real-time temperature updates
💧 Humidity information
🌬️ Wind speed details
☁️ Weather condition descriptions
🎨 Responsive and modern user interface
📱 Mobile-friendly design
⚡ Fast and easy to use


🛠️ Technologies Used
HTML5
CSS3
JavaScript (ES6)
Weather API (OpenWeatherMap or similar API)
